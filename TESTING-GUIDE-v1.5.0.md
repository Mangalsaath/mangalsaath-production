# Testing Guide – v1.5.0

1. Run `npm install` and `npm run dev`.
2. Log in with the demo admin account: `vikas@example.com` / `123456`.
3. Open Dashboard and confirm profile completion and verification panels appear.
4. Edit the profile and confirm expanded partner-preference fields save correctly.
5. Create a member account, complete at least 80% of the profile and request verification.
6. Log in as admin, open Admin, and approve or reject the pending request.
7. Confirm the member dashboard and profile badge reflect the updated verification status.
8. Run `npm run build` before deployment.
