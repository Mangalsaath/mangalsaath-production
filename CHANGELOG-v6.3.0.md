# Changelog v6.3.0 — MySQL Production Foundation

- Migrated runtime persistence from local `db.json` writes to MySQL 8.

- Converted all API database calls to asynchronous MySQL access.
- Added one-time JSON-to-MySQL import utility.
- Added database backup utility.
- Added environment template and production deployment guide.
- Preserved the approved v6.2.3 application behaviour and offer system.
