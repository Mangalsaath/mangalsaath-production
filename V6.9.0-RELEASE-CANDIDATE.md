# Mangalsaath v6.9.0 Release Candidate

Status: Release Candidate — build verified, not yet merged to `main`.

## Included in v6.9.0

- Super Admin-only demo profile permissions.
- Timed demo enable, schedule, extend, disable and emergency-lockdown controls.
- Controlled production viewer access for private client evaluation.
- Demo-access entry and signed viewer session handling.
- Dedicated Super Admin demo control, access and assisted-inbox workspaces.
- Synthetic profile lifecycle controls and audit logging.
- Demo interest/message enforcement and Super Admin-assisted handling.
- Deterministic guarded seeder for 1,005 synthetic demo profiles, hidden by default.
- Minimal Prisma schema additions for synthetic profile state and timing.
- GitHub Upgrade Check CI covering dependency install, Prisma generate/validate, project checks and Next.js production build.

## Safety defaults

- Global demo mode is OFF by default.
- Seeded synthetic profiles are hidden by default.
- Demo interests and messages are OFF by default.
- Production seeding requires both `ALLOW_SYNTHETIC_DEMO_SEED=true` and `CONFIRM_CONTROLLED_DEMO_SEED=YES`.
- Synthetic accounts use a non-login password sentinel and fictional `.invalid` email addresses.
- Unlabeled synthetic profiles are intended only for a controlled client demo session, not unrestricted public presentation.
