# Mangalsaath v6.1.1 Launch Candidate — QR Upload Module

- Replaced the manual QR image path field with an administrator image picker.
- Added live preview, replace and remove controls.
- Added PNG/JPG/JPEG/WEBP validation and a 5 MB limit on both client and server.
- Added file-signature checks and administrator-only upload/delete endpoints.
- Stores the QR image in site configuration so no project-file editing is required.
- Added a friendly member payment fallback when no QR code is configured.
- Added administrator audit records for QR upload and removal.
