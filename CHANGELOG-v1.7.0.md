# Changelog – v1.7.0

## Communication
- Replaced the flat message list with conversation-based chat.
- Added unread message counts, sent/read status and conversation sorting.
- Restricted direct messaging to accepted matrimonial connections.
- Added mobile-responsive conversation and message layouts.

## Interest workflow
- Added accept, reject and withdraw actions.
- Added pending, accepted, rejected and withdrawn states.
- Added connection summaries and action controls.

## Notifications
- Added persistent notification storage and API.
- Added notifications for interests and new messages.
- Added unread badges, individual read action and mark-all-read.

## Platform improvements
- Added automatic migration defaults for communication records.
- Added activity records for interest responses.
- Added dashboard communication widgets.
- Production build verified successfully.
