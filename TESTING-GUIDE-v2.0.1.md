# v2.0.1 Hotfix Testing Guide

1. Start the application with `npm install` and `npm run dev`.
2. From the header, select **Create profile** and confirm the complete registration form appears.
3. Test the homepage and footer Create Profile buttons.
4. Submit an incomplete form and confirm browser-required validation appears.
5. Submit a valid new profile with an 8+ character password and confirm the dashboard opens.
6. Select **Log in**, verify the login form appears, and test an existing account.
7. Repeat on a mobile-width browser.
