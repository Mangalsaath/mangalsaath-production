# Mangalsaath v1.3.0 Beta 1

## Launch-hardening improvements
- Enforced the one-account/one-primary-profile member model.
- Logged-in members are directed to their dashboard rather than profile creation.
- Added optional upload of up to 10 profile photographs during registration.
- Added photo management in Edit My Profile: add, remove and select a primary photo.
- Search cards and detailed profiles display the selected primary photograph.
- Detailed profiles include an optional photo gallery.
- Added file validation: JPG, PNG or WEBP, maximum 2 MB each.
- Added About, Privacy, Terms and Contact public-beta pages.
- Added public Beta labeling in the footer.
- Preserved working interests, messaging, member dashboard and admin activity views.
- Production build and live registration/profile/photo/edit checks passed.

## Public deployment note
This is a public-beta launch candidate. Before accepting real users, configure an official support email, HTTPS hosting, persistent production database/storage, backups, rate limiting, email/mobile verification, and final legal review.
