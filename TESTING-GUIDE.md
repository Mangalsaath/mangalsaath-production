# Mangalsaath v1.3.0 Beta Testing Guide

## Start locally
1. Extract the ZIP.
2. Open `Mangalsaath-Integrated-Final`.
3. Double-click `START-MANGALSAATH-INTEGRATED.bat`.
4. Keep the black window open and visit http://localhost:3000.

## Essential launch test
1. Register one new member with all required details.
2. Add zero photos and confirm registration is allowed.
3. Register another test member and add 1–10 JPG/PNG/WEBP photos.
4. Confirm the primary photo appears in search and View Profile.
5. Open Dashboard and use Edit My Profile.
6. Add/delete photos and choose a different primary photo.
7. Confirm a logged-in user sees Dashboard, not a second Create Profile flow.
8. Send an interest; confirm the button changes to Interest sent and counts update.
9. Send a message and confirm it appears under Messages.
10. Log in as Admin and review members, interests, messages and recent activity.
11. Review About, Privacy, Terms and Contact pages.
12. Test desktop and mobile widths.
