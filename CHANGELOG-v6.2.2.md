# MangalSaath v6.2.2 — Home Page Premium Edition

## Added
- Admin-controlled Homepage Offers module.
- Multiple offers with draft, pending, approved and rejected workflow.
- Priority-based display, scheduling, active/inactive control and automatic expiry.
- Dynamic offer banner placed below the hero image so the couple photograph remains unobstructed.
- Privacy-conscious unique visitor and total visit counter.
- Public trust statistics for visitors, registered members, verified profiles and premium members.
- Admin analytics summary for total visits and unique visitors.
- Four selectable offer themes and configurable CTA destination.

## Changed
- Removed the hardcoded offer card from the hero photograph.
- Removed the duplicate hardcoded launch-offer block from the journey section.
- Homepage promotional content now comes from the Admin Console.
- Version updated to 6.2.2.

## Important production note
The current project uses a JSON-file datastore. Persistent production analytics and admin edits require persistent storage. On serverless hosting, connect a managed database before relying on the counters as permanent business records.
