# Changelog – v1.6.0

## Added
- Advanced profile filters for city, religion, marital status and age range.
- Search sorting by compatibility, recency and age.
- Server-side pagination with total-result metadata.
- Preference-aware compatibility scoring for logged-in members.
- Persistent shortlist stored in the member's browser.
- Dedicated shortlist screen and navigation count.
- Recently-active and verified indicators in discovery results.

## Improved
- Search cards, mobile discovery layout and filter usability.
- No-results guidance, reset controls and pagination states.
- Profiles API input handling and query performance for the current file-based database.

## Verification
- `npm run build` completed successfully with Next.js 16.2.10.
