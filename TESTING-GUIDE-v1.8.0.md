# Testing Guide – v1.8.0

1. Run `npm install` then `npm run build`.
2. Login with demo account `vikas@example.com` / `123456`.
3. Open Membership and verify Free, Premium and Platinum cards.
4. Activate a paid plan in demo mode and confirm plan, expiry and transaction history.
5. Send interests/messages and confirm plan usage increments.
6. As admin, verify premium-member and revenue statistics.
7. Confirm responsive membership layout on mobile widths.

Note: The payment flow is intentionally a demo abstraction; a live gateway and webhook verification are required before accepting real payments.
