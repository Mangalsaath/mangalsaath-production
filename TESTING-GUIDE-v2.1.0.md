# v2.1.0 Testing Guide

1. Run `npm install` then `npm run dev`.
2. Verify top navigation has no About item.
3. Verify About Us appears under Company in the footer.
4. Check hero image, CTA buttons, Search Profiles and Membership navigation.
5. Test mobile widths below 700px.
6. Apply PREMIER on Premium or Platinum and confirm the 20% discount.
7. Run `npm run build` before deployment.
