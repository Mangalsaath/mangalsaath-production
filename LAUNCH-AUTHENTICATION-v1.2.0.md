# MangalSaath v1.2.0 Launch Authentication

## Members
- Register with email, password and mobile number.
- Verify registration through email OTP sent using Hostinger SMTP.
- Mobile starts as unverified and is verified manually when Admin approves the profile.

## Super Admin
- Login with Admin email/username and separate Admin Panel password.
- Provide the configured private security answer.
- Complete email OTP verification through Hostinger SMTP.
- Mobile OTP is deferred to a post-launch release.

## Deferred
- SMS OTP and DLT integration.
- Automated mobile verification.
